## Главное для Recap

**Движение**
- Анимации — `.app` и `.appQuick` из `Motion.swift`, без своих кривых в каждом экране.
- `.animation(_:value:)` — всегда с `value`; цепочки — `withAnimation { } completion: { }`,
  не задержками.
- С `accessibilityReduceMotion` — прозрачность вместо движения (уже так в `Motion`).
- Ступенчатое появление (stagger) — для списков результатов, не для каждого экрана.

**Цифры и символы**
- Счётчики (серия дней, минуты, слова) — `.contentTransition(.numericText())`
  и `.monospacedDigit()`: цифры не прыгают по ширине.
- Смена иконки — `.contentTransition(.symbolEffect(.replace))`.

**Отклик**
- Новый код — `.sensoryFeedback(.success, trigger: …)`; верный ответ — `.success`,
  ошибка — `.error`, выбор варианта — `.selection`. Не вибрировать на каждом нажатии.

**Состояния**
- Пусто — `MascotEmptyState` (свой аналог `ContentUnavailableView` с лосем).
- Загрузка — свой загрузчик (P-35), не системный спиннер; без сдвига раскладки
  при появлении данных.
- Ошибка — по-человечески и с действием «Повторить».

**Типографика и цвет**
- Только `.font(.app(...))` со стилями Dynamic Type; цифры — `monospacedDigit`.
- Цвета — `Theme.*` из каталога ассетов (есть тёмные варианты); без `UIColor`
  и ручной прозрачности, где хватает `.secondary`.
- Касание — не меньше 44×44 pt.

**Виджет и Live Activity** (`Widget/`, `SessionActivityController`)
- Виджет — одна мысль: сколько повторить сегодня и серия; без прокрутки и мелочи.
- Live Activity сессии — прогресс и время, `staleDate`, завершение по концу сессии.

**Мончик как чат** (`EpisodeDiscussionView`, `RetellView`, `MonchikHelpView`)
- Пузыри с группировкой подряд идущих реплик, поле ввода над клавиатурой,
  индикатор «Мончик думает», прокрутка к новому сообщению без рывка.
- Отправка — мягкий отклик; ошибка сети — у самого сообщения, с повтором.

**Камера** (`DocumentCameraView`, `LessonScanner`)
- Перед системным запросом камеры — объяснение зачем (один шанс на разрешение).
- Распознавание — на телефоне (Vision), снимок никуда не уходит; так и сказать
  на экране.
