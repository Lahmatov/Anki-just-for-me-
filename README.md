# Anki just for me

Личное приложение для изучения американского английского: карточки с интервальными
повторениями, произношение, аудирование, пересказ серий с разбором и награды за
реально выученные слова.

## Главный контур

```
посмотрел серию
   → пересказал вслух, о чём она была
   → приложение разобрало: что понял верно и как звучал английский
   → ошибки одной кнопкой стали карточками
   → выучил
   → следующий пересказ лучше
```

Плюс обычный путь: попросил Claude сделать набор по серии — закинул файл в приложение.

## Статус

Все семь итераций написаны и покрыты тестами (365 штук). **Не собрано** — Xcode
есть только у владельца репозитория.

С чего начать — [docs/first-day.md](docs/first-day.md). Как собрать — [BUILD.md](BUILD.md).

Код прошёл пять кругов разбора без компилятора: найдено и исправлено 29 дефектов,
включая четыре, которые блокировали сборку. Логика алгоритмов дополнительно
проверена переносом в Python и прогоном против эталона — так были пойманы
ошибки, которые тесты бы пропустили.

## Что умеет

| | |
|---|---|
| **Повторения** | FSRS-6 (сверен с эталонной py-fsrs), SM-2, коробки Лейтнера, зубрёжка — выбираются на уровне набора |
| **Очередь** | лимиты новых и повторов, «братья» одного слова разносятся по дням, учебный день кончается в 4 утра |
| **Типы карточек** | узнавание, ввод, на слух, правописание, произношение, пропуск в предложении |
| **Проверка ввода** | прощает регистр, артикли, «to», апостроф и одну опечатку — кроме карточек правописания |
| **Звук** | системный синтезатор офлайн, принудительно лучший голос, замедление |
| **Произношение** | запись и распознавание на устройстве, 18 минимальных пар под русский акцент, шэдоуинг |
| **Пересказ** | разбор по субтитрам с цитатами, оценка понимания и языка, ошибки → карточки |
| **Награды** | контракты «150 слов — и покупаю себе диск», 13 достижений, недельные цели |
| **Контекст** | подстановка живых фраз из субтитров, YouGlish, поиск по словам |
| **Быт** | графики нагрузки и роста, трудные карточки с советами, автобэкап раз в неделю |

## Структура

| Где | Что |
|---|---|
| `Core/` | Ядро без зависимостей от Apple: алгоритмы повторений, форматы, разбор субтитров, оценка произношения, награды. Тестируется через `swift test` за секунду |
| `App/` | Приложение: модели SwiftData, сервисы, экраны |
| `project.yml` | Проект Xcode генерируется отсюда через XcodeGen |

Правило простое: **логика по умолчанию живёт в `Core/`**. Что там — проверяется
без Xcode, а значит будет проверяться на самом деле.

напоминания. Платный только разбор пересказов: около €3 в месяц при серии в день
