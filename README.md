# Anki just for me

Личное приложение для изучения американского английского: карточки + интервальные повторения
+ произношение + аудирование + правописание + геймификация с реальными наградами.

Главный контур: посмотрел серию → пересказал вслух, о чём она → приложение разобрало,
что понял верно и как звучал твой английский → ошибки превратились в карточки → учишь.

## Статус

Итерация 0 написана: импорт наборов, база, экраны, бэкап. Как собрать — [BUILD.md](BUILD.md).

## Структура

| Где | Что |
|---|---|
| `Core/` | Ядро без зависимостей от Apple: формат наборов, нормализация слов, план импорта. Тестируется через `swift test` без симулятора |
| `App/` | Приложение: модели SwiftData, сервисы импорта и экспорта, экраны |
| `project.yml` | Проект Xcode генерируется отсюда через XcodeGen |
