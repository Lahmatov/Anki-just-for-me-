# Формат набора карточек

Это то, что генерирует Claude по запросу «сделай набор по серии» и что ты закидываешь
в приложение. Формат специально простой: один JSON-файл, читаемый глазами.

## Минимальный пример

```json
{
  "format": "ajfm-deck",
  "version": 1,
  "deck": {
    "name": "Breaking Bad S03E05",
    "folder": "Сериалы/Breaking Bad",
    "language": "en-US",
    "scheduler": "fsrs6",
    "cardTypes": ["recognition", "recall", "listening", "pronunciation"]
  },
  "notes": [
    {
      "term": "to pull off",
      "translation": "провернуть, суметь сделать",
      "ipa": "/pʊl ɒf/",
      "partOfSpeech": "phrasal verb",
      "example": "I can't believe you pulled that off.",
      "exampleTranslation": "Не верится, что ты это провернул.",
      "cloze": "I can't believe you ___ that ___.",
      "note": "В сцене в гараже, про сделку.",
      "tags": ["phrasal", "s03e05"],
      "difficulty": "medium"
    }
  ]
}
```

## Поля

### `deck`

| Поле | Обяз. | Описание |
|---|---|---|
| `name` | да | Название набора |
| `folder` | нет | Путь папки, вложенность через `/`. Создаётся автоматически |
| `language` | нет | По умолчанию `en-US` |
| `scheduler` | нет | `fsrs6` (по умолчанию) · `sm2` · `leitner` · `cram` |
| `cardTypes` | нет | Какие карточки генерировать из каждой записи. По умолчанию `["recognition", "recall"]` |
| `source` | нет | Свободный текст: откуда набор (сериал, книга, урок) |

### `notes[]`

| Поле | Обяз. | Описание |
|---|---|---|
| `term` | да | Английское слово или фраза |
| `translation` | да | Перевод на русский |
| `ipa` | нет | Транскрипция, американская |
| `partOfSpeech` | нет | `noun`/`verb`/`adjective`/`adverb`/`phrasal verb`/`idiom`/`phrase` |
| `example` | нет | Пример употребления — **лучше реальная фраза из серии** |
| `exampleTranslation` | нет | Перевод примера |
| `cloze` | нет | Тот же пример с `___` на месте изучаемого — для карточки с пропуском |
| `synonyms` | нет | Массив строк — принимаются как верный ответ при вводе |
| `note` | нет | Заметка: контекст сцены, нюанс употребления, ложный друг |
| `tags` | нет | Массив меток |
| `difficulty` | нет | `easy`/`medium`/`hard` — влияет на стартовый приоритет |
| `audio` | нет | Имя файла рядом с JSON, если хочется свой звук вместо синтеза |

## Правила для генерации (инструкция для Claude)

1. `example` — **всегда из контекста**, о котором просил пользователь. Оторванные от жизни
   примеры из словаря работают заметно хуже: смысл всей затеи в том, что ты уже видел эту
   фразу в знакомой сцене.
2. `cloze` строится из `example`, пропуск — ровно на изучаемом слове.
3. Транскрипция — американская (`/ˈtoʊ.mə.toʊ/`, не `/təˈmɑː.təʊ/`).
4. Для фразовых глаголов и идиом `partOfSpeech` обязателен — они требуют других карточек,
   чем обычные слова.
5. Не больше ~30 записей в наборе: больше — это неподъёмная очередь новых карточек.
6. Не дублировать слова, которые уже есть в других наборах (если пользователь дал список).
7. `translation` — короткий, 1–3 варианта через запятую. Длинные определения ломают проверку ввода.
