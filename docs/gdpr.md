# GDPR: как Recap обращается с данными

_P-73, октябрь 2026. Внутренний документ оператора: реестр обработки (ст. 30),
обработчики, сроки, процедуры для запросов людей и утечек. Публичная версия
для людей — docs/legal/privacy.*.md; сроки в ней сверяет тест
`backend/test/privacy.test.ts`._

## Принцип

Учёба живёт на телефоне. Сервер получает только то, без чего функция не
работает, и не хранит тексты: запросы, уроки, субтитры, разговоры уходят в
Anthropic и забываются. Исключения — облачный бэкап (по выбору, зашифрован) и
обращения в поддержку (человек сам пишет их нам).

## Реестр обработки (ст. 30)

| Обработка | Данные | Основание | Где | Срок |
|---|---|---|---|---|
| Учёт устройства | случайный номер, хеш токена, даты, версия приложения в запросе | договор 6(1)(b) | D1 | 12 мес. без связи (`RETENTION.inactiveDeviceDays`) |
| Аккаунт (вход Apple) | HMAC номера Apple, зашифрованный токен для отзыва | договор | D1 | до удаления; 12 мес. без входа и телефонов |
| Подписка и лимит | номер транзакции, товар, срок, расход | договор | D1 | пока привязана; 30 дней после конца |
| ИИ-запросы (наборы, уроки, разговоры, помощник) | текст запроса — **не хранится**; число токенов | договор; учёт расходов — законный интерес 6(1)(f) | Anthropic (до 30 дней по их условиям), D1 — только токены | токены 90 дней |
| Облачный бэкап | сжатая зашифрованная база учёбы | договор, по выбору человека | D1 или R2 | 7 копий на язык; с данными/аккаунтом |
| Поддержка | тема, текст, почта (по желанию), диагностика, ответ | договор; законный интерес | D1, письмо владельцу через Cloudflare Email | год после ответа |
| Защита от злоупотреблений | номер устройства или HMAC IP в счётчиках | законный интерес | D1 | до суток |

Чего нет: рекламы, трекинга, профилирования, продажи данных, автоматических
решений со значимыми последствиями (ст. 22). Возраст — от 13 лет (ст. 8, в
Португалии 13).

## Обработчики (ст. 28)

| Кто | Что делает | Где | Договор |
|---|---|---|---|
| Cloudflare, Inc. | Workers, D1, R2, Email Routing | США/ЕС | DPA Cloudflare, ССК ЕС, DPF |
| Anthropic, PBC | модель Claude | США | коммерческие условия + DPA, ССК, без обучения на данных API |
| Apple | вход, покупки | — | Apple — самостоятельный оператор для Apple ID и покупок |

Новый обработчик (например, PostHog для аналитики) — только после: DPA,
записи сюда и в политику, согласия в приложении, если это не строго
необходимо. Для PostHog — сервер в ЕС, без записи сессий по умолчанию.

## Запросы людей (ст. 15–22)

Срок ответа — месяц (ст. 12(3)). Человек находится по **коду поддержки**
(«Профиль») или по номеру обращения: почты и имён на сервере нет.

| Просьба | Что делаем |
|---|---|
| Доступ, переносимость | в приложении «Профиль → Мои данные на сервере» — файл JSON; иначе — `npm run support -- export КОД` |
| Удаление | в приложении «Удалить все данные» / «Удалить аккаунт»; иначе — `npm run support -- erase КОД --yes`; объекты R2 стираются сразу |
| Исправление | данных для исправления на сервере почти нет; бэкап — пересоздать |
| Возражение (законный интерес) | счётчики и журнал токенов нужны для защиты; объясняем и при необходимости удаляем устройство |
| Через поддержку | тема «Мои данные» (`category = privacy`) — такие обращения первыми в очереди |

Каждый запрос — запись в обращении (номер, дата, что сделано). Это и есть
журнал исполнения прав.

### Как удалить данные по просьбе

Чаще всего человеку ничего не нужно от тебя: в приложении есть «Удалить все
данные» и «Удалить аккаунт». Ответь шаблоном из docs/support.md. Если
приложения уже нет (потерял телефон, удалил) или человек просит сам:

1. **Найти, кого удалять.** Нужен код поддержки (`ABCD-1234`, «Профиль») или
   номер обращения (`R-7K2Q9X`). Имени и почты на сервере нет — по ним найти
   нельзя, и это нормально: так и пишешь, «пришлите код или номер обращения».
   Письмо с почты само по себе не доказывает, что телефон его: код знает
   только владелец телефона.
2. **Удалить:**
   ```sh
   cd backend
   export RECAP_URL=https://recap-backend.<имя>.workers.dev
   export RECAP_ADMIN_TOKEN=…            # из менеджера паролей
   npm run support -- erase ABCD-1234        # покажет, что будет удалено
   npm run support -- erase ABCD-1234 --yes  # удалит
   ```
   Удаляется то же, что кнопками: телефон, его серии, расход, обращения,
   облачные копии (и в R2), промо-доступ; если был вход — аккаунт, и вход
   у Apple отзывается. Другие телефоны того же аккаунта остаются
   отдельными записями — у каждого свой код.
3. **Чего удалить нельзя и нужно сказать:** подписка принадлежит Apple ID —
   отменяет её человек в настройках Apple; данные на самом телефоне стираются
   удалением приложения; копии у Anthropic (до 30 дней, без обучения)
   удаляются сами.
4. **Ответить** человеку: что удалено и когда. Само обращение удаляется
   вместе с данными, поэтому подтверждением служит твой ответ — письмо
   остаётся в почте поддержки (ст. 5(2): показать, что просьба исполнена).
   Если просьба пришла обращением без почты — ответь `reply` до удаления.
5. **Выгрузка** вместо удаления: `npm run support -- export КОД` → файл
   `data-КОД.json` — приложи к ответу и удали у себя после отправки
   (`data-*.json` в `.gitignore`, в репозиторий не попадёт).

Срок — месяц (GDPR), для жителей США — 45 дней (docs/us-privacy.md).

## Утечка (ст. 33–34)

1. Заметил — сразу: `DISABLED_FEATURES=all`, сменить затронутые секреты
   (`wrangler secret put`), `wrangler rollback`, если причина в коде.
2. В течение **72 часов** — уведомление в CNPD (www.cnpd.pt): что случилось,
   какие данные, сколько людей, что сделано.
3. Если риск высокий — сообщить людям: в приложении (ответом в обращениях
   или экраном при запуске) и письмом тем, кто оставлял почту.
4. Затронуты жители США — им то же письмо; если их больше 500 в Калифорнии,
   ещё и уведомление генеральному прокурору штата (docs/us-privacy.md, «Утечки»).
5. Запись сюда: дата, причина, решение.

Что ограничивает ущерб заранее: токены и промокоды — только хеши, номер Apple
и IP — HMAC, бэкапы зашифрованы ключом сервера и номером снимка, тексты
запросов не хранятся вовсе.

## Чек-лист для новой функции

- Можно ли сделать на телефоне? Если да — делаем там (как OCR уроков).
- Что уходит на сервер, и нужно ли хранить? По умолчанию — не хранить.
- Если хранить: таблица → срок в `retention.ts` → строка в политике (тест
  `privacy.test.ts` проверит числа) → выгрузка в `/v1/me/export` → удаление в
  «Удалить все данные» и при удалении аккаунта → тест на всё это.
- Новый обработчик — раздел выше.
- Никаких личных данных в журналах (`console.*` — только имена ошибок и номера).
