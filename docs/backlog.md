      выбор модели в настройках (Opus 5 по умолчанию)
- [ ] **4.5** Промпт разбора: судить строго по субтитрам, каждое утверждение — с цитатой,
      не больше 3 главных замечаний
- [ ] **4.6** Экран результата: две оси — понимание (верно / неверно / упустил / покрытие)

- [ ] **4.7** Отсечка субтитров по таймкоду — защита от спойлеров

- [ ] 🔴 **4.9** **Ошибки → карточки.** Из разбора одной кнопкой создаётся набор: слова,
      которых не хватило; повторяющиеся грамматические ошибки; фразы из непонятых сцен.
      Это замыкает главный контур приложения
- [ ] **4.10** История пересказов и прогресс: покрытие событий, ошибки на 100 слов, темп речи

**Готово, когда:** посмотрел серию → пересказал → получил честный конкретный разбор →
одной кнопкой сделал из своих ошибок набор карточек.
