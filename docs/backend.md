# Сервер Recap: подписка, промокоды, каталог

Сервер нужен для трёх вещей, которые нельзя сделать в самом приложении
безопасно:

1. **Ключ Anthropic для подписчиков.** Ключ не может лежать в приложении:
   из скачанного из App Store файла его достанут за минуты. Поэтому модель
   вызывает сервер, а приложение — сервер.
2. **Промокоды.** Проверка кода на телефоне — это проверка, которую
   взломанная копия приложения просто пропустит. Коды живут только на
   сервере, и то в виде хешей.
3. **Каталог** — готовые наборы слов к первым сезонам топ-50 сериалов,
   один раз собранные моделью и раздаваемые всем бесплатно.

Код — `backend/`: Cloudflare Workers (TypeScript) и база D1 (SQLite).
Бесплатного тарифа Cloudflare хватает: 100 000 запросов в день, 5 ГБ базы.

## Как это устроено

```
iPhone ──HTTPS──► Worker (backend/src) ──► Anthropic API   (ключ в секрете Worker)
                     │                 ──► TVMaze          (номер серии → описание)
                     │                 ──► App Store API   (проверка подписки)
                     ▼
                  D1: устройства, доступ, хеши промокодов, каталог, расход
```

| Путь | Что делает | Нужна подписка |
|---|---|---|
| `POST /v1/devices` | регистрация устройства, выдаёт токен | нет |
| `GET /v1/me` | статус доступа и остаток лимита | нет |
| `DELETE /v1/me` | стереть устройство и его данные | нет |
| `POST /v1/promo/redeem` | погасить промокод | нет |
| `POST /v1/subscription/verify` | проверить покупку у Apple | нет |
| `GET /v1/catalog`, `/v1/catalog/{id}` | каталог сериалов | нет |
| `POST /v1/deck` | слова к серии: из каталога — бесплатно, иначе модель | для модели |
| `POST /v1/discuss` | реплика Мончика о серии | да |

### Лимит

Считается в **единицах**: токены входа плюс токены выхода × 5 (так
соотносятся цены модели Haiku, $1 и $5 за миллион). 2 000 000 единиц в
месяц ≈ $2 расходов на Anthropic ≈ 100 наборов по 20 слов или сотни реплик
разговора. Меняется переменными `SUBSCRIPTION_UNITS` и `PROMO_UNITS`
в `wrangler.toml` — без перевыпуска приложения.

Перед каждым запросом к модели единицы **бронируются** по худшему случаю
одним условным `UPDATE`, после ответа списывается фактический расход.
Параллельные запросы не могут вместе выйти за лимит.

## Безопасность: от чего защищено

| Угроза | Защита |
|---|---|
| Достать ключ Anthropic из приложения | В приложении ключа нет. Только `wrangler secret`. |
| Использовать ИИ как бесплатный чат обо всём | Промпты собирает сервер. Клиент присылает только номер серии, язык, уровень и (по желанию) субтитры. Описание серии сервер берёт в TVMaze сам. Разговор разрешён только о сериях, к которым устройство уже получило слова. Ответ ограничен JSON-схемой и `max_tokens` (600 для разговора). Реплики не длиннее 600 символов, не больше 6 ответов. |
| Инъекция промпта через субтитры или реплики | Всё пользовательское обёрнуто в теги и помечено как данные. Выход — только слова по схеме или короткая реплика; тратится при этом лимит самого пользователя. |
| Подделать подписку | Сервер не верит приложению: по номеру транзакции он сам спрашивает статус у App Store Server API, подписав запрос ключом ES256. Сверяются приложение, товар, срок и отзыв покупки. |
| Раздать подписку друзьям | Одна покупка — общий лимит и не больше `MAX_DEVICES_PER_SUBSCRIPTION` устройств (по умолчанию 3). Лишнее отвязывается — то, что дольше всех не выходило на связь. |
| Подобрать промокод | 80 бит случайности (16 символов Crockford), 5 попыток в час на устройство, 20 в час на IP. Ответ одинаковый для «нет такого», «уже использован» и «истёк». |
| Утечка базы | Токены устройств — только SHA-256. Промокоды — только HMAC-SHA256 с секретным перцем. IP — только HMAC. Текстов запросов и ответов нет нигде: ни в базе, ни в журнале. |
| Двойное гашение промокода | Один атомарный `UPDATE … WHERE redeemed_at IS NULL`. |
| Разорить счёт Anthropic | Лимит на устройство и покупку, бронь, 6 запросов в минуту и 150 в день на устройство, регистрации ограничены по IP. Бесплатные устройства к модели не допускаются вовсе. **И обязательно — месячный лимит расходов на сам ключ в Anthropic Console.** |
| Огромные запросы | Тело ≤ 300 КБ, строго `application/json`, проверка каждого поля. |
| Утечка подробностей | Клиент получает код ошибки. Стеки, SQL и ответы Anthropic и Apple наружу не выходят. |

Что остаётся и как усилить позже:

- **Номер транзакции чужой подписки.** Если человек сам отдаст свой номер,
  можно привязать его подписку к своему телефону (в пределах лимита
  устройств). Номера нигде не видны, а при смене телефона нужна как раз
  такая привязка. Усилить можно через App Attest, см. ниже.
- **App Attest** (DeviceCheck) докажет, что запросы идут от настоящего
  приложения на настоящем iPhone. Это следующий шаг, когда у приложения
  появятся пользователи. Проверка аттестации на сервере — отдельная работа
  (CBOR, цепочка сертификатов Apple).

## Развернуть сервер — по шагам

Нужен Node.js 22+ и бесплатный аккаунт Cloudflare.

```sh
cd backend
npm ci
npm test                       # 52 теста на настоящем SQLite
npx wrangler login             # откроется браузер
npx wrangler d1 create recap   # скопировать database_id в wrangler.toml
npx wrangler d1 migrations apply recap --remote
```

Секреты (каждая команда спросит значение; в файлы они не пишутся):

```sh
npx wrangler secret put ANTHROPIC_API_KEY     # отдельный ключ только для сервера
npx wrangler secret put PROMO_PEPPER          # содержимое secrets/promo-pepper.txt
```

Выкатить:

```sh
npm run deploy     # напечатает адрес: https://recap-backend.<имя>.workers.dev
```

Адрес вписать в `project.yml` → `RecapBackendURL`, затем `xcodegen` и
собрать приложение. Пока там заглушка `CHANGE-ME`, приложение работает
по-старому: со своим ключом и без Recap Plus.

**Ключ Anthropic для сервера:** в [console.anthropic.com](https://console.anthropic.com)
создать отдельный ключ и сразу поставить **месячный лимит расходов** на
организацию (Settings → Limits). Это последняя линия обороны: даже при
ошибке в коде счёт не уйдёт дальше лимита.

## Промокоды

100 кодов на 30 дней уже выпущены (партия `launch`). Они лежат локально в
`backend/secrets/`, в git не попадают:

- `promo-codes-launch.txt` — сами коды, раздавать людям;
- `promo-seed-launch.sql` — хеши для базы;
- `promo-pepper.txt` — перец, он же секрет `PROMO_PEPPER`.

Загрузить в базу:

```sh
npx wrangler d1 execute recap --remote --file secrets/promo-seed-launch.sql
```

Новая партия (тот же перец подхватится из `secrets/promo-pepper.txt`):

```sh
npm run promo -- --count 50 --days 90 --batch friends --expires 2027-06-30
```

⚠️ Храни эти три файла в менеджере паролей. Без перца коды из базы не
проверить. Если перец потерян — нужен новый перец и новые коды.

Статистика по кодам (сколько погашено):

```sh
npx wrangler d1 execute recap --remote --command \
  "SELECT batch, COUNT(*) total, COUNT(redeemed_at) used FROM promo_codes GROUP BY batch"
```

## Подписка в App Store Connect

1. **Agreements, Tax, and Banking** → подписать Paid Apps Agreement,
   заполнить банк и налоги. Без этого покупки не работают даже в песочнице
   TestFlight.
2. **Твоё приложение → Subscriptions** → группа «Recap Plus», в ней товары
   с идентификаторами:
   - `com.lahmatov.ajfm.plus.monthly` — на месяц;
   - `com.lahmatov.ajfm.plus.yearly` — на год.

   Те же идентификаторы — в `SUBSCRIPTION_PRODUCTS` (`wrangler.toml`) и
   `RecapAccount.productIDs` (приложение).
3. **Users and Access → Integrations → In-App Purchase** → создать ключ,
   скачать `.p8` (скачивается один раз!), записать Key ID и Issuer ID.
4. Секреты сервера:

   ```sh
   npx wrangler secret put APPSTORE_KEY_ID
   npx wrangler secret put APPSTORE_ISSUER_ID
   npx wrangler secret put APPSTORE_PRIVATE_KEY   # вставить весь текст .p8
   ```

5. Проверить покупку в песочнице: TestFlight-сборка → Настройки → Recap
   Plus → купить тестовым Apple ID. Сервер сам поймёт, что это песочница.

Цена: при себестоимости ~$2 за 2 000 000 единиц подписка от $4.99 в месяц
окупается даже с комиссией Apple 30%. С Small Business Program комиссия 15%.

## Каталог: топ-50 сериалов

Список — `backend/catalog/shows.json`: 50 сериалов, у каждого пометка
акцента (US/UK/CA). Слова к каждой серии первого сезона собирает модель
**один раз** через Message Batches API (вдвое дешевле обычных запросов),
сразу на трёх языках: переводы ru и pt и английское определение.

```sh
cd backend
export ANTHROPIC_API_KEY=...        # ключ в переменной, не в файле
npm run catalog -- plan             # найдёт сериалы в TVMaze, посчитает цену
npm run catalog -- submit           # отправит пакет
npm run catalog -- status           # обычно готово за час
npm run catalog -- collect          # соберёт catalog/out/seed.sql
npx wrangler d1 execute recap --remote --file catalog/out/seed.sql
```

Цена на Haiku 4.5 — около $7–15 за ~700 серий (`plan` покажет точнее).
Модель меняется флагом `--model`, например `--model claude-sonnet-5-5`:
качество выше, цена примерно вдвое больше.

Готовые наборы отдаются всем бесплатно, в том числе без подписки: модель
уже отработала за всех. Серия, к которой взят набор из каталога, открывает
разговор с Мончиком — но сам разговор только по подписке.
