# Видение

## Для кого

Один пользователь. Учит американский английский. Смотрит сериалы в оригинале.
Дизайн не важен — важна понятность и скорость.

## Главный сценарий

1. Посмотрел серию, выписал/запомнил незнакомые слова и фразы.
2. Попросил Claude: «сделай набор карточек по этим словам из Breaking Bad S03E05».
3. Claude отдаёт файл набора (JSON) с переводом, транскрипцией, примером из контекста,
   уровнем сложности.
4. Файл попадает в приложение с телефона (через «Поделиться» / Файлы / iCloud Drive).
5. Приложение раскладывает слова по карточкам разных типов и ставит их в очередь повторений.

## Что приложение умеет проверять

| Режим | Что показываем | Что делает пользователь | Что проверяем |
|---|---|---|---|
| Узнавание | английское слово | выбирает перевод из 4 | пассивный словарь |
| Воспроизведение | русский перевод | печатает английское | активный словарь |
| Аудирование | только звук | печатает что услышал | восприятие на слух |
| Правописание | звук + перевод | печатает слово | орфография |
| Произношение | слово/фраза | произносит вслух | произношение (скоринг) |
| Пропуск (cloze) | предложение с ___ | вписывает слово | слово в контексте |
| Шэдоуинг | эталонное аудио фразы | повторяет за диктором | темп, интонация |

## Геймификация

Не абстрактные очки, а **контракты на награду**: «150 слов в долгосрочной памяти → диск с игрой».
Пользователь сам заводит контракт (цель + награда), приложение честно считает прогресс и
в момент достижения показывает «Заслужено. Иди покупай».

Плюс ачивки за осмысленные вехи (первые 100 зрелых слов, 30 дней без пропусков,
идеальное произношение 20 раз подряд и т.п.) — не больше 15 штук, чтобы не обесценивались.

## Чего НЕ делаем

- Не делаем многопользовательский сервис, регистрацию, подписки, аккаунты.
- Не делаем свой бэкенд, пока не докажем, что без него нельзя.
- Не делаем красивый дизайн на старте — системные контролы SwiftUI и всё.
- Не публикуем в App Store (и, следовательно, не упираемся в вопросы авторских прав на контент).
