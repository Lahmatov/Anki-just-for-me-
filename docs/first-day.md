# Первый день

Порядок действий от «склонировал» до «учусь». Каждый шаг проверяемый: если что-то
не совпало, дальше можно не идти — проще сказать мне, что именно сломалось.

## 1. Собрать (15 минут)

```sh
brew install xcodegen
cd Anki-just-for-me-
xcodegen generate
open AJFM.xcodeproj
```

Впиши Team ID в `Config/Signing.xcconfig` (Xcode → Settings → Accounts → твой Apple ID,
колонка Team ID). Выбери iPhone в списке устройств вверху, нажми ⌘R.

**Сначала — тесты.** Они быстрые и покажут, цела ли логика:

```sh
cd Core && swift test     # 240+ тестов ядра, без симулятора, за пару секунд
```

В Xcode ⌘U прогонит остальные — те, что работают с базой.

> Код не собирался ни разу: Mac есть только у тебя. Ошибки компиляции возможны,
> и это нормально — кидай текст, поправлю.

## 2. Проверить, что приложение живое (5 минут)

1. Открой вкладку **Наборы** → меню справа сверху → **Вставить из буфера**.
2. Скопируй содержимое `examples/retelling-vocabulary.json` и вставь.
3. Должно показать превью: **20 слов, 80 карточек**, папка «Базовое», алгоритм FSRS-6.
4. Нажми «Добавить».

Если превью показалось и набор появился — импорт работает. Этот набор выбран не
случайно: это слова, без которых трудно рассказать, о чём была серия, — то есть
прямая подготовка к главной фиче.

## 3. Первая сессия (10 минут)

Вкладка **Сегодня** → «Учить 20 карточек».

На что посмотреть:

- на кнопках оценок стоят интервалы — они должны быть разными и расти слева направо;
- карточка «на слух» не показывает ни слова, ни перевода, только звук;
- в ответе есть кнопка озвучки слова и примера.

**Если голос звучит роботом** — это ожидаемо на свежем телефоне. Настройки iOS →
Универсальный доступ → Устный контент → Голоса → English (US) → скачай голос
с пометкой «Улучшенный» или «Премиум». Приложение подхватит его само; в Настройках
на вкладке «Звук» видно, какой голос выбран.

## 4. Произношение (5 минут)

Вкладка **Речь** → «Минимальные пары».

Приложение попросит доступ к микрофону и распознаванию речи — оба нужны, оба
работают локально.

Скажи «ship». Потом намеренно скажи «sheep». Если во втором случае приложение
сообщит, что услышало другое слово, — проверка работает так, как задумано.

Обрати внимание: нигде не будет написано «Отлично!». Только «распознано как X
с уверенностью Y» — потому что распознаватель подгоняет услышанное под словарь
и мягкой оценке верить нельзя. Честный сигнал дают именно пары.

## 5. Награда (2 минуты)

Вкладка **Награды** → «Завести цель».

Поставь что-нибудь настоящее: «150 слов — покупаю себе диск» или «50 слов — пицца».
Цель считается от текущего числа выученных слов, а выученным слово становится,
когда его интервал дорастает до 21 дня. То есть за вечер награду не накликать —
в этом и смысл.

## 6. Пересказ — когда посмотришь серию

Понадобятся две вещи:

1. **Ключ API.** Настройки → «Разбор пересказов» → вставь ключ. Он уходит в Keychain,
   в репозиторий не попадает. Лимит по умолчанию €10 в месяц; реальный расход
   около €3 при серии в день.
2. **Субтитры серии** в `.srt` или `.vtt`. Без них разбор не запустится — и это
   намеренно: без эталона модель судит о содержании по своим воспоминаниям
   о сериале и начинает сообщать об ошибках, которых не было.

Дальше: вкладка **Речь** → «Пересказать серию» → загрузи субтитры → отметь,
до какой минуты досмотрел → говори две-пять минут по-английски.

**Обязательно поправь расшифровку** перед разбором. Распознавание путается
на акценте, и если оставить «serious» там, где ты сказал «furious», разбор решит,
что ты не понял сцену.

В конце — кнопка «Сделать карточки из ошибок». Вот ради неё всё и затевалось.

## 7. Дальше каждый день

- Утром или вечером — сессия из вкладки «Сегодня» (можно поставить напоминание
  в Настройках).
- Посмотрел серию — пересказал, сделал карточки из ошибок.
- Нужен набор по конкретным словам — меню в «Наборах» → «Запрос для Claude»,
  скопирует готовый текст, который останется прислать мне.

Раз в неделю приложение само пишет бэкап в «Файлы» → AJFM → Backups.
Восстановление — там же в меню. Синхронизации между устройствами нет
(для неё нужен платный аккаунт Apple), так что бэкап — единственная страховка.

## Если что-то пошло не так

| Симптом | Что смотреть |
|---|---|
| Не собирается | Текст ошибки — мне. Код ни разу не компилировался |
| Приложение перестало запускаться через неделю | Так и должно быть на бесплатном аккаунте: подключи телефон и нажми ⌘R снова |
| Голос роботом | Скачать улучшенный голос в настройках iOS, см. шаг 3 |
| Разбор пересказа не запускается | Нет ключа API или не загружены субтитры |
| «Лимит исчерпан» | Настройки → «Разбор пересказов» → поднять лимит |
| Карточек нет, хотя набор импортирован | Все карточки уже показаны сегодня — так работают лимиты и разнесение слов |
