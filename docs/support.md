# Поддержка Recap

_P-72. Как человек просит помощи и как ты отвечаешь._

## Три уровня

1. **Частые вопросы** — «Помощь» в приложении, мгновенно и офлайн (HelpCenter).
2. **Спросить Мончика** — ИИ-помощник по приложению, бесплатно, с лимитами.
3. **Человек** — «Помощь → Написать в поддержку»: тема, текст, почта по
   желанию, диагностика (версии и языки). Обращение получает номер `R-XXXXXX`,
   ответ видно в «Мои обращения». Без сервера — письмом (mailto), с кодом
   поддержки в теле.

## Как отвечать

```sh
cd backend
npm run support                         # открытые, старые сверху
npm run support -- show R-7K2Q9X        # целиком, с диагностикой и почтой
npm run support -- reply R-7K2Q9X "Починили в 0.5 — обнови приложение."
npm run support -- close R-7K2Q9X       # спам, дубль
```

Если подключена почта (ниже), о каждом новом обращении приходит письмо;
«Ответить» в почте уходит человеку напрямую, если он оставил адрес. Ответ в
приложении — через `reply`: он виден, даже если почты нет.

## Почта (по желанию)

1. Домен в Cloudflare → Email Routing → включить, подтвердить свой ящик.
2. В `wrangler.toml`:
   ```toml
   [[send_email]]
   name = "SUPPORT_MAIL"
   destination_address = "твой@ящик"
   ```
   и в `[vars]`: `SUPPORT_FROM = "support@твой-домен"`, `SUPPORT_TO = "твой@ящик"`.
3. Деплой. Без этих строк обращения просто копятся в базе.

## Сроки и приоритет

| Тема | Цель ответа |
|---|---|
| «Мои данные» (privacy) | 3 дня; по закону не позже месяца (docs/gdpr.md) |
| «Подписка и оплата» | 2 дня; возвраты — через Apple (reportaproblem.apple.com) |
| «Что-то сломалось» | 3 дня; повторяется у многих — `DISABLED_FEATURES` и исправление |
| Вопрос, идея | неделя |

## Шаблоны ответов

- **Возврат денег:** «Платежи принимает Apple — возврат оформляется на
  reportaproblem.apple.com. Подписку можно отменить в Настройках → Apple ID →
  Подписки.»
- **Обнови приложение:** «Исправили в версии X — обнови Recap в App Store.»
- **Удаление данных:** «Профиль → Конфиденциальность → Удалить все данные стирает
  всё на телефоне и на сервере. Если приложения уже нет — пришли код поддержки,
  удалю вручную.»

## Что улучшать по обращениям

Раз в месяц: `npm run support` по темам → частые вопросы — в HelpCenter
(ядро, с тестом), частые поломки — в план. Обращения хранятся год после
ответа и удаляются вместе с данными человека.
