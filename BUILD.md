# Сборка

## Один раз

```sh
brew install xcodegen
```

## Одна команда, которая проверит всё

```sh
./tools/check.sh
```

Сгенерирует проект, прогонит тесты ядра, соберёт приложение под симулятор
и — если что-то сломалось — сложит **только ошибки** в `build-errors.txt`.
Этот файл можно прислать мне целиком: в нём нет тысячи строк обычного вывода
`xcodebuild`, только то, что надо чинить.

```sh
./tools/check.sh core   # только тесты ядра, пара секунд
./tools/check.sh app    # только сборка приложения
python3 tools/lint.py   # статические проверки, работают даже без Xcode
```

Линтер ловит то, что уже дважды оказывалось блокером сборки: пропущенный
импорт и публичную структуру без `public init` (синтезированный —
internal, и создать такую структуру из приложения нельзя). Проверено
на настоящих дефектах — ловит оба.

Код ни разу не компилировался — Mac есть только у тебя, — так что в первый
раз ошибки почти наверняка будут. Это ожидаемо: пришли файл, поправлю.

## Каждый раз, когда меняется структура проекта

```sh
cd Anki-just-for-me-
xcodegen generate
open AJFM.xcodeproj
```

`AJFM.xcodeproj` не лежит в репозитории — он собирается из `project.yml`.
Так структура проекта видна текстом в diff'ах, а не прячется внутри
неразбираемого файла.

## Подпись

Впиши свой Team ID в `Config/Signing.xcconfig` — один раз, перегенерация его не сотрёт.
Где взять: Xcode → Settings → Accounts → твой Apple ID → колонка Team ID.

Дальше: выбрать iPhone в списке устройств вверху и нажать ⌘R.

**Про бесплатный аккаунт.** Сборка живёт 7 дней, потом приложение перестанет
запускаться — надо подключить телефон и снова нажать ⌘R. Данные при этом не теряются,
но бэкап всё равно делай (меню наверху → «Сохранить бэкап»).

Bundle ID (`com.lahmatov.ajfm`) менять не стоит: на бесплатном аккаунте лимит
примерно 10 новых App ID за 7 дней, и каждая смена его расходует.

## Тесты

Тесты разложены по двум уровням — чтобы то, что можно проверить быстро,
проверялось действительно быстро.

**Ядро** — разбор наборов, нормализация слов, план импорта, формат бэкапа,
а дальше и алгоритмы повторений. Без зависимостей от Apple-фреймворков,
поэтому гоняется без Xcode и за секунду:

```sh
cd Core && swift test
```

**Приложение** — работа с базой: импорт, дедупликация, создание папок, экспорт,
каскадное удаление, метрика «выучено». Нужен симулятор, запускается из Xcode
по **⌘U** (или `xcodebuild test -scheme AJFM -destination 'platform=iOS Simulator,name=iPhone 16'`).

Тесты базы работают целиком в памяти — на диске после них ничего не остаётся.

Правила, по которым пишутся тесты, — в [CLAUDE.md](CLAUDE.md).
