# Сборка

## Один раз

```sh
brew install xcodegen
```

## Каждый раз, когда меняется структура проекта

```sh
cd Anki-just-for-me-
xcodegen generate
open AJFM.xcodeproj
```

`AJFM.xcodeproj` не лежит в репозитории — он собирается из `project.yml`.
Так структура проекта видна текстом в diff'ах, а не прячется внутри
неразбираемого файла.

## Подпись

Впиши свой Team ID в `Config/Signing.xcconfig` — один раз, перегенерация его не сотрёт.
Где взять: Xcode → Settings → Accounts → твой Apple ID → колонка Team ID.

Дальше: выбрать iPhone в списке устройств вверху и нажать ⌘R.

**Про бесплатный аккаунт.** Сборка живёт 7 дней, потом приложение перестанет
запускаться — надо подключить телефон и снова нажать ⌘R. Данные при этом не теряются,
но бэкап всё равно делай (меню наверху → «Сохранить бэкап»).

Bundle ID (`com.lahmatov.ajfm`) менять не стоит: на бесплатном аккаунте лимит
примерно 10 новых App ID за 7 дней, и каждая смена его расходует.

## Тесты логики

Ядро (разбор наборов, нормализация слов, план импорта, а дальше — алгоритмы
повторений) лежит отдельным пакетом без зависимостей от Apple-фреймворков,
поэтому гоняется без симулятора и за секунду:

```sh
cd Core
swift test
```

Это главная страховка: всё, что можно проверить до сборки, проверяется здесь.
